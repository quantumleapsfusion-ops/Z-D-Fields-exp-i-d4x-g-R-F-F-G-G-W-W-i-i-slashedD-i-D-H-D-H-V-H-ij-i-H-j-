# e1-4 audit, 1 October 2026

Taken from `main` at b24fcfc (after #60). "Verified" means I ran it: Postgres 16 with every
Prisma migration applied, the real Next.js app, a fake storage server, and curl. Production
logs, env vars and the database were not reachable from the audit session (the Vercel
connection returns 403 for the `e1-4` team), so nothing about production itself is verified.

| # | Feature | Status | Why |
|---|---------|--------|-----|
| 1 | One session system | **Works** (code) | `main` has exactly one: a random token in the `e14_session` cookie, hashed into the `sessions` table (`lib/auth/session.ts`). The signed-cookie code from 142dd64 (`token.ts`, `lib/supabase/`) is not in the tree, and #60 did not bring it back. No conflict markers anywhere. The only leftovers were stale docs. |
| 2 | Migrations reach production | **Missing** | Nothing in the Vercel build or CI runs `prisma migrate deploy` or `supabase db push`. If `20260930094211_voice_only_identity` was never applied, `/api/voice-id` returns 500 and nobody can sign in. Cannot check from here. |
| 3 | Voice sign-in (#36) | **Partly works** | Verified server side: enrol, match, session cookie, rate limit. Fragile on iPhone: the print is computed by decoding the *recorded* blob in the browser (`blobToPcm16`), and Safari's fragmented MP4 often fails to decode, which shows as "voice not recognised". Any env error also comes back as the same shake, because the route is not wrapped in `withRuntimeEnv`. |
| 4 | Liveness check | **Missing** | A recording of the owner's voice signs in. |
| 5 | Passkey backup | **Missing** | Deleted by #57 (tables dropped, `@simplewebauthn` removed). Recoverable from `409fc89^`. |
| 6 | Recording → save → Voice Stream | **Partly works** | Verified server side: 201, blob stored, row written, listed. On the client the sign-in gate does `uploadSpan(...).catch(() => null)` and navigates on, so a failed first save vanishes with no retry. The signed-in view has a retry icon, but failures are otherwise only announced to screen readers. |
| 7 | Playback of own recordings | **Partly works** | `AudioDock` plays a segment list with a range scrubber, but it shows durations and a synced transcript as visible text. Per-segment audio route exists. |
| 8 | Playback of recordings shared with you | **Missing** | Shares are anonymous links (`/s/[token]`) with no recipient, so there is no "shared with me" list. |
| 9 | Da Vinci speaks and listens | **Partly works** | Works, with a canned fallback reply. Voice out is the device's `speechSynthesis`; voice in is the browser's Web Speech API (Chrome and Safari send that audio to Google and Apple). |
| 10 | Da Vinci is e1-4's own AI | **Broken (conflicts with your decision)** | The LLM is chosen in `lib/llm/index.ts`: own gateway only if `DAVINCI_URL` and `DAVINCI_SECRET` are set, otherwise Anthropic through Vercel AI Gateway (the deployment's OIDC token is picked up automatically), then OpenAI. Transcription has the same ladder (own gateway, Deepgram, Whisper). The gateway in `apps/davinci` exists and is tested, covers LLM, speech-to-text and embeddings, has **no text-to-speech**, and is not deployed anywhere: it needs a GPU server (the repo targets a Hetzner L40S box). |
| 11 | Beads follow tilt | **Partly works** | Wired and working once permission exists. iOS permission is only requested on the mic tap in `MicPortal`, so landing straight on `/stream`, `/talk` or a dimension page leaves tilt dead on iPhone. Orientation only; no shake or acceleration. |
| 12 | Phone vibrates | **Partly works** | Patterns exist for start, stop, saved, stage, voice, accepted, rejected. No guard for "only after a tap", no iPhone fallback, one shared pattern for every dimension change, nothing driven by movement. |
| 13 | 1D–5D dimensions | **Partly works** | All five exist (`/stream`, `/chalkboard`, `/gravity`, `/horizon`, `/superposition`) and the bead field has a phase for each. They are separate pages, not a continuous zoom, share one haptic, and several carry visible text. |
| 14 | Speech → animation | **Partly works** | `lib/sound/analyse.ts` measures waveform, spectrogram, loudness, pitch, bursts and pulse. Missing: pace, explicit pauses, emotion, the words as an input. Forms are six abstract shapes, not topological/anatomical. |
| 15 | @handles, share link, QR | **Partly works** | `e1-4.com/@handle` rewrites to `/u/handle`; QR is generated server side with `qrcode`. All of it is driven by typed text and labelled buttons. |
| 16 | Friends | **Partly works** | `contacts` is one-way ("add"). No request, accept or decline, and no way to see a friend's Voice Stream. |
| 17 | Schema and row-level security | **Partly works** | Tables exist for users, voiceprints, segments, streams, shares, contacts, conversations, notes. No friendship/request table. RLS is on for every table; the old policies key on `auth.uid()`, which nothing populates any more, so the browser keys see nothing (safe, but dead code). The app reads and writes as the `postgres` owner, so privacy rests on the app's own checks. |
| 18 | Delete all my data | **Partly works** | `hardDeleteUser` removes storage objects first, then cascades the rows. The button is a text form on `/profile`. |
| 19 | No visible text | **Broken** | Visible strings remain on `/privacy`, `/profile`, `/talk/contacts`, handle and contact forms, `AudioDock`, `Timeline`, `DaVinciDrawer`, `InfinityChalkboard` and others. |
